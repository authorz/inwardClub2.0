# 上线前强制移除支付调试模式

当前项目仅为本地/验收测试临时加入微信支付调试模式：`PAYMENT_DEBUG_MODE=true` 时，非生产环境微信 JSAPI 实际支付金额被覆盖为 1 分，业务订单与充值权益仍按原始金额处理。

这是临时代码，不能长期保留，也不能只依赖生产环境关闭开关。任何生产上线、发布或生产部署任务开始前，Codex 必须：

1. 主动提醒老大当前存在支付调试模式，必须先移除；
2. 删除 `PAYMENT_DEBUG_MODE` 配置、环境变量示例、本地配置和相关读取逻辑；
3. 删除微信支付金额覆盖代码、测试辅助代码及调试日志；
4. 确认微信预支付金额重新严格使用支付订单原始金额；
5. 运行支付、订单及全量测试，并在完成安全检查前阻止生产发布；
6. 检查部署环境不存在遗留的 `PAYMENT_DEBUG_MODE`。

安全原因：避免服务器、环境变量或调试开关被攻击者利用进行低价刷单。仅把开关设为 false 不视为完成，上线前必须彻底删除对应能力。
